# LeadFlow Portfolio Comparison — V1 vs isolated V2

| Criterion | Original V1 | Evidence-led V2 |
| --- | --- | --- |
| Positioning | Visual sales-operations product story | Engineering case study for SaaS/API/automation buyers |
| Landing presentation | Immersive animated workflow and CRM demo | Editorial engineering-first hero and execution console |
| API | Actual Cloudflare Pages qualification endpoint | Actual new Cloudflare Pages server execution with contract tests |
| Qualification | Server-backed deterministic rules | Server-backed deterministic rules with visible explainable factors |
| CRM state | Browser-local records and dashboards | Browser-local records and explicit unique-record replay testing |
| Integration proof | Provider-neutral integrations illustrated | CRM sandbox contract + explicit no-provider-write declaration |
| Reliability | Reliability lab and planned exceptions | Executable synthetic fault injection with 2 retries and receipt |
| Trace | Dynamic guided execution events | Server-generated event trace with timestamps and JSON export |
| Tests | Historical QA documentation and tests | 6 Node tests + live HTTP + desktop/mobile Chromium interaction checks |
| Client presentation | Rich visual storytelling | Evidence and system boundary disclosure |
| External AI / HubSpot / CRM | Not provider-verified | Not configured; not claimed |
| Payment / real customer results | Not claimed | Not claimed |

## Assessment

V2 is better for small, technically precise integration scopes where the buyer wants to verify code behavior.
V1 may be more appealing for nontechnical buyers who want to imagine their finished CRM and automation interface.
They serve different intents: **keep both until owner review of live experiences and media**.

## Potential Upwork positioning

V1: Product Design / Interactive SaaS / Dashboard Workflow Design.
V2: Automation Engineer / API Integration / Server-Side Lead Qualification.
Do not imply an LLM was used for V2's scoring or a third-party CRM actually accepted writes.
