# Project Case Studies

This directory is the public evidence layer for selected SaamVR products whose production source is partly or entirely private.

The goal is not to reproduce proprietary repositories. Each case study documents the **problem, product boundary, architecture, engineering decisions, reliability strategy, and demonstrable outcome** at a level useful to clients and technical reviewers.

## Case studies

- [EZComo / EcomCMS](./ezcomo-ecomcms.md) — multi-tenant commerce CMS and storefront platform
- [SM Manager](./sm-manager.md) — conversational commerce system
- [Virtual Agent](./virtual-agent.md) — embeddable 3D AI receptionist
- [Booking Agent](./booking-agent.md) — conversational booking SaaS

Public/live work remains linked from the root [Portfolio README](../README.md).

## Evidence policy

Private code, credentials, tenant data, infrastructure secrets and commercially sensitive implementation details are excluded. Technical claims are based on the corresponding repository documentation and current product architecture. Repository history can be demonstrated privately when appropriate.
