# NOVA V5 — portfolio finish

V5 develops the existing NOVA concept into a clearer product experience and a credible client-facing portfolio case study.

## What was working

- The warm ivory, near-black and copper direction gives the product a recognizable identity.
- A real animated headphone, folding controls and direct inspection demonstrate more than a static mockup.
- The chapter sequence provides a useful structure for product storytelling.
- Reference specifications and an independent-concept disclosure give the content a traceable basis.

## What changed

- Corrected product normalization: hidden cable descendants no longer alter the bounding box, scale or rotation center.
- Introduced responsive product zones, preserving space for copy and keeping the complete silhouette visible.
- Kept one spring responsible for inspection rotation; removed duplicate smoothing, added a continuous reset and controlled release inertia.
- Improved low-frame-rate integration and paused rendering in hidden tabs and the case-study section.
- Reworked typography, spacing, dark controls and chapter copy; condensed implementation details into a disclosure.
- Added a visible reduced-motion control, inactive-section focus gating, dialog focus containment and restoration, and disabled unavailable 3D controls.
- Replaced the approximate fallback silhouette with a transparent render of the actual asset.
- Added V5 sharing metadata, a favicon, a focused case study and a copyable project brief for Upwork conversations.

## Scope and attribution

This is an independent concept, not a storefront or a commissioned Sony website. The supplied model is not claimed as original modeling work. Sony WH-1000XM6 specifications are disclosed as a reference benchmark, not measured properties of the depicted asset. Codec and noise controls demonstrate visual states; they do not process audio. The brief button copies text and sends no data.

## Verification

The release workflow verifies source motion contracts and rendered chapters at 1440×1000, 1440×800, 1024×768, 430×932, 390×844 and 360×740. It checks product/copy separation, viewport bounds, preset/reset/drag/fold interactions, dialog keyboard handling, mobile navigation, reduced motion and fallback assets. Public verification repeats the journey against the deployed V5 URL. Exact run and deployment identifiers are recorded in the release handoff.

Automated browser evidence uses Chromium with software WebGL. It is not a claim of physical-device or all-browser certification.
